## Reto 3.1 · nivel medio · Actualización anidada sin mutar

Un pedido tiene líneas: `{ id: number; customer: string; lines: { productId: number; quantity: number }[] }`. Escribe `changeQuantity(order, productId, quantity)` que devuelva un pedido **nuevo**, sin tocar el original y **reutilizando** las líneas que no cambian. Si la cantidad es `0`, la línea desaparece.

---

## Reto 3.2 · nivel medio · Memoización con `Map` y closure

`memoize(fn: (n: number) => number): (n: number) => number` devuelve una versión de `fn` que **recuerda** resultados ya calculados. Pruébala contando cuántas veces se ejecuta la función original.

---

## Reto 3.3 · nivel avanzado · Operaciones de conjuntos

Isaías FL tiene dos listas de correo: `currentStudents` y `formerStudents` (arrays de emails, con repetidos). Con los métodos de `Set` de ES2025 calcula: todos sin repetir, los que están en ambas y los que solo son alumnado actual.

---

## Reto 4.1 · nivel medio · Máquina de estados de un pedido

Con la unión discriminada `OrderState` (pendiente, pagado, enviado, cancelado), escribe `transition(p, event)` donde `event` es `{ type: 'pay'; date: string } | { type: 'ship'; tracking: string } | { type: 'cancel'; reason: string }`. Solo se permiten las transiciones lógicas; si no, devuelve el mismo pedido. `switch` exhaustivo.

---

## Reto 4.2 · nivel avanzado · Validador genérico de listas

Escribe `isListOf<T>(raw: unknown, isT: (x: unknown) => x is T): raw is T[]` y úsala con un guard `isTask` para validar un JSON.
